# Weapon Icons

Original Arknights: Endfield weapon icons used by the RotationForge loadout UI.

- Source index: https://endfield.wiki.gg/wiki/Category:Weapon_icons
- 76 current weapon icons retrieved in their original PNG resolution through
  the wiki's public MediaWiki API on 2026-08-01.
- Run `tools/sync-endfield-weapons.py` to refresh the catalog migration and icons.
- Arknights: Endfield and its assets belong to their respective rights holders.
